# Transformação e preparação de dados

Projeto de portfólio sobre exploração, limpeza, transformação e preparação de dados para Machine Learning.

## O que foi desenvolvido
- análise estatística de variáveis numéricas e categóricas;
- tratamento de valores ausentes;
- inspeção de outliers;
- engenharia de atributos;
- análise de correlação;
- transformação logarítmica;
- normalização Min-Max;
- comparação de regressão linear antes/depois da transformação.

## Tecnologias
Python · Pandas · NumPy · Matplotlib · Seaborn · Scikit-learn

## Dados
O notebook utiliza o Titanic `train.csv` e uma base de imóveis usada no material original. Os arquivos de dados não estão incluídos neste repositório. Consulte o notebook para os caminhos esperados.

## Como executar
```bash
pip install -r requirements.txt
jupyter notebook Transformacao_de_dados_portfolio.ipynb
```
